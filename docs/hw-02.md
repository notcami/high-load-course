# hw-02

## Что именно не работало/падало ()

acc-5, 2 заказа/с, 100 заказов, дедлайн оплаты 60 секунд.
Разрешения аккаунта: 3 запроса/с, 5 одновременных запросов, среднее время ответа - 4,9 с.

Без ограничения параллельности при такой нагрузке одновременно выполнялось бы около `2 * 4.9 = 9.8 > 5`. Провайдер бы отклонял запросы из-за превышения.

## Что изменено

Ограничение скорости через фиксированный интервал заменено на sliding window: учитываются разрешения, выданные за последнюю секунду.

## Почему не упало

В первом кейсе уже был добавлен семафор, ограничивающий параллельность по свойствам аккаунта, поэтому для acc-5 допускается не больше 5 одновременных запросов. Остальные задачи ждут окончания обрабатвающихся, их ожидание ограничено дедлайном с резервом.
